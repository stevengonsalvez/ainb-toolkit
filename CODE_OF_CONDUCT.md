# Code of Conduct

## Expected behavior

Treat contributors with respect. Give technical feedback about the work, not
the person. Do not harass, discriminate, publish private information, or use
the project to target others.

## Scope

This applies to project spaces and to public interactions representing this
project.

## Reporting

Use GitHub's report-content controls for conduct in GitHub discussions,
comments, and issues. For security-sensitive conduct, use the private
vulnerability reporting path in [SECURITY.md](SECURITY.md).

## Enforcement

Maintainers may remove content, restrict participation, or take other
reasonable action to protect the project community.
